# BinTracker v0.2.0-alpha.6.2.4 — User Administration Polish

## Fixed
- Widened Activate / Deactivate so its label is no longer clipped at high DPI.
- Widened the Status column so "Active — change password required" is visible.
- Increased the default Users window width.

## Added
- Administrators can now change a user's role after account creation.
- Supported transitions include Viewer, Operator, and Administrator.
- Role changes are audited.
- A signed-in administrator cannot remove their own Administrator role.
