# BinTracker v0.4.0-alpha.15 — Manual Container Mapping

- Added **Map container tokens...** to Import Review.
- Unknown explicit tokens such as `(Tub)` can be mapped to an existing Container Type.
- Added **Manage Container Types...** from the mapping dialog so missing types can be created without abandoning the import workflow.
- Mapping choices refresh after Container Type management.
- Applied mappings immediately rebuild Review and Balance Reconciliation.
- Mappings persist for the current wizard session only.
- Unknown unmapped tokens remain hard blockers.
- Import execution remains disabled.
