# BinTracker v0.2.0-alpha.7.2.9 — Embedded Icons & Password Visibility

## Navigation
- Replaced Segoe MDL2 font glyphs with actual embedded transparent PNG icons.
- Dashboard, Customers, Batch Entry, Single Entry, Reports and Settings now render consistently on every workstation.
- No external icon files need to be installed.

## Logout
- Added a matching embedded logout icon beside the Logout text.

## Password entry
- Added show/hide eye buttons to:
  - Login
  - Change Password (current, new and confirmation)
  - First-run Administrator setup
  - Add User temporary password
  - Reset Password temporary password and confirmation
- Passwords remain hidden by default.
- Toggling visibility keeps focus/caret in the password box.
