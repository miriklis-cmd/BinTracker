# BinTracker v0.2.0-alpha.7.2 — Draft Editing & Layout Polish

- Clicking a pending Batch Entry line loads it into the entry fields.
- Customer position switches to the selected line's customer.
- Add to Batch becomes Update Line while editing.
- Esc cancels edit mode.
- Removing/updating a line recalculates With Draft immediately.
- Batch action buttons now use identical alignment settings.
- User Role column widened so Administrator fits; Display Name narrowed slightly.
- Customer current-position/history areas were rebalanced for smaller screens.
