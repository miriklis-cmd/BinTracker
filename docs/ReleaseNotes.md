# BinTracker v0.1.0-alpha.3

## Added

- First-run administrator setup
- Login screen
- Secure PBKDF2-SHA256 password hashing with per-user random salts
- Administrator, Operator and Viewer roles
- User management screen
- User activation/deactivation
- Append-only audit event table
- Successful login, failed login and logout audit events
- User creation and status-change audit events
- Computer and session identifiers on audit records
- Audit log viewer for administrators
- Existing Alpha 2 database upgrade without deleting data
