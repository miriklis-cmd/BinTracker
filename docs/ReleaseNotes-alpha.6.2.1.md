# BinTracker v0.2.0-alpha.6.2.1 — Settings Stabilisation

## Fixed
- Fixed the blank Settings screen introduced in Alpha 6.2.
- Replaced the incompatible FlowLayoutPanel stacking approach with a DPI-safe TableLayoutPanel.
- My Profile now renders display name, username, role, login time, session ID, and Change Password.
- Administration now renders Manage Users and View Audit Trail for administrators.
- Settings sections use fixed, explicit content layouts so child controls cannot collapse to zero height.

## Scope
This is a bug-fix-only release. No new business functionality was added.
