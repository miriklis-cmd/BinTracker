# BinTracker v0.2.0-alpha.6.2.3 — User Management Layout

## Add User
- Increased the dialog height for high-DPI displays.
- Removed the unnecessary normal-workflow vertical scrollbar.
- The bottom action bar remains fixed and visible.

## Users
- Replaced separate Active, Locked, and Change Password checkbox columns with one readable Status column.
- Status displays Active, Locked, Inactive, or Active — password change required.
- Retained separate internal account state fields; only the presentation was simplified.
- Increased the default Users window width.
- Grid columns now size to avoid horizontal scrolling at normal supported display sizes.
- User selection is restored after Activate/Deactivate, Reset Password, and Lock/Unlock operations.
