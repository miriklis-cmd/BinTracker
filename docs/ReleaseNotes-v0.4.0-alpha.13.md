# BinTracker v0.4.0-alpha.13 — Authoritative Balance Reconciliation

- Added read-only balance reconciliation planning.
- Excel B/Fwd is authoritative at cutover.
- Existing BinTracker balances are reconciled to B/Fwd rather than added to Excel.
- Cutover-day OUT/IN remain visible as real movements in the plan.
- Added a Balance reconciliation tab to Review.
- Shows Current, B/Fwd, OUT, IN, Excel target, Opening adjustment, Projected and Status.
- Fresh and populated databases use the same formula.
- Import remains disabled.
