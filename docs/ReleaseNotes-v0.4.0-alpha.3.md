# BinTracker v0.4.0-alpha.3 — Import Wizard Layout

- Rebuilt the Excel Import Wizard UI to match the approved design.
- Import Wizard remains a separate, resizable modal window.
- Added clear Analyse / Map / Review / Import step indicator.
- Browse and Analyse controls are always visible.
- Added workbook structure summary grid.
- Added detected customer candidate sample grid.
- Added clear read-only notice that no data is imported during analysis.
- Added disabled Next button for the upcoming mapping stage.
- Added DPI-safe minimum sizing and scroll fallback to prevent clipping.
- Large/custom workbooks show the first 100 candidate rows while retaining the full analysis result.
