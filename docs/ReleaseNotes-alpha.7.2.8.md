# BinTracker v0.2.0-alpha.7.2.8 — Header & Navigation Polish

## Page titles
- Fixed the slight clipping visible on page titles such as Dashboard and Customers.
- Shared header height increased slightly.
- Page title labels now AutoSize rather than relying on a fixed rendering box.
- Added a small bottom padding allowance for DPI-scaled Segoe UI glyphs.

## Navigation
- Added Windows-native icons to Dashboard, Customers, Batch Entry, Single Entry, Reports and Settings.
- Icons use the built-in Segoe MDL2 Assets font.
- No image files or custom fonts are bundled with BinTracker.
- Icon and caption both activate the same navigation action.

No database or business-rule changes.
