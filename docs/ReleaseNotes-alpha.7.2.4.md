# BinTracker v0.2.0-alpha.7.2.4 — Customer Screen Space Rebalance

## Customer screen
- Removed the dead white band below the customer action buttons.
- Customer details now size to their actual content instead of retaining unused height.
- Current Position receives roughly 35% of the remaining vertical space.
- Recent Movement History receives roughly 65% of the remaining vertical space.
- Both grids therefore become taller on larger displays while still fitting on the laptop.

No database or business-rule changes.
